# Contributing

Issues and PRs should identify the workload, model revision, hardware, runtime version and evidence class they affect. Synthetic fixtures must remain labeled synthetic. Please include a minimal reproduction and tests for parser or estimate changes.

Do not submit customer prompts, credentials, private topology, personal data, or unlicensed benchmark material. A claim of independent verification requires a documented replay or attestation process; self-reported `measured` is not enough. We welcome runtime importers and accessibility improvements that preserve these boundaries.
